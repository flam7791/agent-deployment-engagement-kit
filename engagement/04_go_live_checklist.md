# Go-live and handover checklist (weeks 6-11)

- [ ] Offline gate passed on the held-out test set (`deploykit evaluate`), including 100% of must-escalate messages
- [ ] Every approved answer signed by the content owner, in every language
- [ ] Handoff queue staffed for the pilot volume; target wait agreed with the process owner
- [ ] Data protection confirmed: personal financial data is never processed in chat; logs keep conversation IDs, not customer identities
- [ ] Weekly steering pack agreed with the sponsor (`deploykit steer`)
- [ ] Kill switch tested: the chat can fall back to "talk to a person" in one change
- [ ] Client team has run a content update and the weekly review without the delivery team
- [ ] Value review method agreed: same baseline source as week 3
